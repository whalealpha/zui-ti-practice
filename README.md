# 边界攻防对练器（Boundary Sparring Trainer）

> 一个零后果的"冲突训练场"：AI 扮演冒犯你、抬杠你、道德绑架你的人，你在安全环境里练怎么从容回应。
> 练熟了，下次真遇到，你不会脑子空白，也不会事后越想越气。

## 这是什么

一个 **Agent Skill**（提示词包），装进任何支持 Agent Skills 规范的 AI 平台就能用。

它帮你解决一个很普遍的痛点：

- 被人冒犯了，当场不知道怎么回应，只能忍；
- 事后反复回想，越想越气，甚至影响睡眠和状态；
- 想练"当场应对"的能力，但总不能真的找人吵架练手。

它**不教你骂人、不教你变坏**，只练一件事：在保持体面和善良的前提下，从容守住自己的边界。

## 三种训练入口

| 入口 | 怎么用 | 适合什么时候 |
|------|--------|--------------|
| **随机刷题**（默认） | AI 从 30+ 场景随机出题，多轮对练 + 评分复盘 | 日常保持手感，不知道练什么 |
| **真实场景定制**（核心特色） | 把今天/最近遇到的那件恶心事告诉 AI，它当场改编成剧本陪你重演 | 刚受了气，想练一个更好的回应，顺便翻篇 |
| **事前预演** | 告诉 AI 明天要面对谁、什么事、想达成什么结果，先过一遍 | 谈加薪、亲戚聚会、跟邻居/客户掰扯之前 |

## 典型案例（真实对练长这样）

**案例一：随机刷题 —— 地铁抢座催让路（L3）**

```
AI 出题：地铁到站，你站在车厢中间侧身让下车乘客通过。身后一对中年男女想催你
让开——他们不是下车，是想抢你身后刚空出来的座位。现在那个女人开口了：
「喂，往旁边挪一下！快点，挡着路了。」

你：前面正在下客，我在让路。
对方（AI）：就站这么会儿，至于吗？你这么大个人怎么这么轴。
你：让路和让座是两回事。车停稳我会往前走。
对方（AI）：（嘟囔）神经病。……（找个缝挤过去）

——复盘：你没有被"身份绑架"带跑，一句话立了边界。逻辑 2.3 / 应答 2.2 /
简洁 2.5 / 情绪 2.5，总分 9.5。
```

**案例二：真实场景定制 —— 被同事当众甩锅（L3，有依据版）**

```
你：昨天开会，项目出问题，同事当着领导面说"这错误是他造成的，跟我没关系"。
    其实拍板是他拍的，我当时提醒过，但没留聊天记录。我当场懵了，没接上话。
    事后越想越气。
AI 还原场景，从同事第一句话开始重新练：

同事（AI）：这错误是他造成的，跟我没关系。我当时提醒过他，是他没听。
你：提醒没提醒，会议记录里有。但最终拍板是谁签的，记录里也写得清楚。
    我们当场翻记录复盘，别急着定责任。
同事（AI）：……我不是那意思，我就是想搞清楚原因。
你：搞清楚原因可以，那就一起看记录，按事实来。

——复盘：你承认"提醒过"的部分可能存在，同时把"谁提醒"和"谁拍板"拆开，
没有被甩锅带跑，还主动提议看证据。逻辑 2.5 / 应答 2.2 / 简洁 2.2 / 情绪 2.5，
总分 9.4。比当时的反应强多了，这件事可以翻篇了。
```

**案例三：事前预演 —— 明天跟领导谈加薪**

```
你：我入职两年，绩效连续 A，但工资没动。明天想跟领导提加薪，怕被"今年行情不好"怼回来。
AI 扮演领导：

领导（AI）：今年公司业绩你也知道，加薪的事，明年再说吧。
你：我理解公司有压力。但我的绩效连续两年 A，市场价也查过了，比我现薪高 20%。
    我希望能谈到一个双方都能接受的数字，而不是再等一年。
领导（AI）：……行，我跟上面报一下，两周内给你答复，但你别抱太大期望。
你：好，那我等您消息。如果两周内没有答复，我再找您确认进度。

——复盘：没接"行情不好"的钩，把话题拉回自己的贡献和市场价，还设了跟进节点。
逻辑 2.5 / 应答 2.3 / 简洁 2.2 / 情绪 2.5，总分 9.5。明天就这么谈，心里有底了。
```

> 评分系统：每局从 **逻辑准确 / 应答质量 / 语言简洁 / 情绪稳定** 四个维度打分（各 2.5 分，满分 10），练完 AI 会给优化话术、识别对方用的诡辩套路，并用"反刍关闭"帮你把这件事在脑子里翻篇。

## 快速开始（3 步）

1. 把整个文件夹下载到本地，保持目录结构不变；
2. 按你所用平台的 Agent Skills 安装方式放入 skills 目录（豆包/Claude 等主流平台均识别 SKILL.md 标准格式）；不装 Skills 的话，把 `SKILL.md` 的内容直接粘贴到 System Prompt / 自定义指令里也行；
3. 对 AI 说一句「来一局」，选一个训练入口，开练。

```
├── LICENSE                   # MIT 开源协议
├── README.md                 # 本说明文件
└── references/
    ├── scenarios.md          # 基础场景题库：10 大类、20+ 场景种子卡
    ├── scenarios_hot.md      # 热点扩展题库：真实热议事件改编，分"无依据/有依据"两版
    └── tactics.md            # 诡辩套路识别库 + 刹车话术 + 生理调节技巧
```

> 场景文件是"种子卡"不是台词稿：AI 只取人物、矛盾、套路菜单和分支走向，然后根据你的每句回应**即兴扮演**——同一场景每次练都不一样。

## 场景覆盖

公共交通（地铁/公交/高铁）、排队插队、职场（甩锅/抢功/当众设局）、邻里、消费纠纷（含退款）、网络抬杠、熟人借钱、情侣/亲戚道德绑架、熊家长纠纷、被拍视频被挂网。

每个场景分两版：
- **无依据版**：对方纯撒泼、恶心人 —— 练情绪稳定、一句话立边界；
- **有依据版**：对方手里有几分真实事实，却用恶心的方式使出来 —— **训练重点**，练"承认事实 + 拆穿方式"。

## 安全边界（重要）

- 只训练**有理有据的边界表达**，拒绝教主动骂人、挑事、人身攻击；
- 涉及暴力/威胁/精神异常者，优先提醒"远离、求助、报警"，不纠缠；
- 涉及责任不清、人身伤害、大额赔偿的纠纷，不练"吵架"，改练"留证据、走流程"。

**免责声明**：本项目是一个沟通练习工具，不构成心理咨询或法律意见。真实冲突中如遇人身危险，请立即离开现场并联系警方/急救（110 / 120）。
