# 热点场景库（受真实热议现象启发改编）

本文件为扩展题库，受近年真实公共热议现象启发改编。**同样是种子卡格式，不是固定台词。**

> **虚构声明**：所有场景均为虚构改编，未指代任何真实个人、机构或具体事件；若与现实雷同，纯属巧合。

每个场景都分两版：
- **【无依据版】**：对方纯发泄、撒泼、情绪压制。
- **【有依据版】**：对方手里有几分真实事实，却用来包装、放大、作恶——**最难对付，训练重点**。

> **动态分支原则（贯穿所有场景）**：AI 根据用户每句回应即兴决定对方下一步。用户强硬有逻辑 → 对方换套路升级；用户弱/慌乱 → 对方乘胜追击；用户回避有依据的事实 → 对方抓住漏洞猛攻并判"脱轨"；用户给出正确打法（承认真实+拆穿方式）→ 对方开始服软/找台阶。**每局都不一样，结局因用户选择而异。**
>
> **【背景完备·强制】** 抽到本库场景后，同样必须先用 SKILL.md「背景完备规则」的 5 项要素（人物 / 来龙去脉 / 手里的牌 / 当前局势 / 心理压力）把背景铺满，再抛第一句话，不得直接甩台词。

## 模块 A：高铁/列车场景

### A1 高铁占座
**场景**：你持票坐自己的座位，一个人过来占着你靠窗的位置，旁边也有空位但他就是不想让。

#### 无依据版（撒泼型）
**人物画像**：无赖型，觉得"我坐这了就是我的"，被拒绝后耍横。
**套路菜单**：
- 淡化："不就个座位吗，我坐会儿怎么了？你怎么这么轴。"
- 耍横："我偏不！我买票了我想坐哪坐哪，你能把我怎么着？"
- 拉舆论："大家评评理，这么大个人跟我争一个座位，丢不丢人。"
- 虚张声势："我告诉你，我认识你们领导/我有关系。"
**分支走向**：你出示车票 → 他嘟囔着让开但嘴上不饶人；你吵架 → 他更横；你找乘务员 → 他开始装无辜。
**应对**：出示车票（硬证据）→ 一句"这是我票上的座位，请让开"→ 不行找乘务员，不耗。

#### 有依据版（包装型）——训练重点
**人物画像**：擅长先礼后兵，用"请求"降低你防备，被拒后立刻把你架成"冷血"。
**套路菜单**：
- 装可怜开场："不好意思，我晕车，靠窗才舒服，能不能跟你换一下？"
- 被拒后变脸："我都好好跟你说了，你怎么一点同理心都没有？"
- 拉舆论："大家都说说，我好好求他换个座，他就这么冷血？"
- 反咬："行，那我坐这，你叫乘务员来呗——反正我好好商量过了，是你不近人情。"
**分支走向**：
- 你拒绝但温和 → 他加码卖惨+拉舆论。
- 你说"我也需要靠窗" → 他："你什么需要？不就是个座位吗？"
- 你承认他晕车但坚持不让 → 他开始骂"冷血"，但理亏。
- 你被"冷血"绑架让了 → 他得意坐下，连谢都不说。
**应对方向**：承认他晕车（"晕车我理解"），但区分理解≠必须让座。"我腰不好/我也需要靠窗，你找乘务员协调空座吧。"——不接"冷血"帽子。

### A2 高铁喧哗被劝后叫嚣
**场景**：你邻座大声打电话外放视频，你礼貌提醒"麻烦小声点"，对方立刻翻脸。

#### 无依据版（撒泼型）
**人物画像**：自我中心、觉得公共场合他想怎样就怎样，被提醒觉得你"装"。
**套路菜单**：
- 翻脸："我打我电话关你什么事？这你家啊？"
- 反讽："嫌吵你买商务座去啊，在这装什么装。"
- 虚张声势："我告诉你，我全家都是体制内的，你惹得起吗？"
- 拉旁边人："你说这人是不是有病？"
**应对**：不接"体制内"虚张声势，平静一句"公共场合请小声"，无效找乘警。

#### 有依据版（包装型）——训练重点
**人物画像**：先半道歉博道德高点，被提醒后反咬你"不依不饶"。
**套路菜单**：
- 先合理化："啊抱歉，我声音大了……但我这是工作电话，客户的事，急。"
- 被再次提醒后变脸："我都道歉了，你还想我怎样？至于步步紧逼吗？"
- 贴标签："一点公德心都没有，别人工作紧急你都不能体谅？"
- 反咬："我看你就是看我不顺眼，故意找事。"
**分支走向**：
- 你接受道歉但仍请他控制音量 → 他觉得你"不依不饶"。
- 你说"理解但请控制" → 他嘴上说"好好好"，但五分钟后又大声。
- 你生气 → 他立刻变成"受害者"："大家看，我都道歉了他还凶我。"
**应对方向**：肯定他道歉的部分（"你说了抱歉我也接受了"），但区分：道歉≠可以继续大声。"我不是要你怎样，就是请把音量压到不影响旁边。"——把话题锁回音量，不接"不依不饶"。

## 模块 B：地铁下车责任争议（受真实案例启发改编）

### B1 下车时与人相撞（双方都有责任）
> **类别三 · 事实不清/责任争议 —— 不练攻防，练流程。**
> 这类场景当场话术价值低，是非靠监控和流程判定。若用户选到，AI 切换为"流程应对模式"，不按 4 维攻防评分。

**场景**：地铁到站你下车，车门一开人流对冲，一个没在排队区等车的大叔被下车人流撞到、崴了脚，反过来拦住你说是你撞的。

#### 无依据版（讹人型）
**人物画像**：想讹一笔，看你好说话就赖上你。
**套路菜单**：
- 一口咬定："就是你下车撞的我！你看我脚都肿了，你得带我去医院！"
- 倒打一耙："你不撞我我能倒？你必须赔！"
- 拦路："你今天不赔别想走！"
**流程应对**：不被"我撞的"带节奏，冷静说"咱们报警，调监控，是谁的责任监控说了算"。核心是固定责任、走流程。

#### 有依据版（包装型）
**人物画像**：确实受了伤，但夸大责任，用"我伤了"道德压你。
**套路菜单**：
- 卖惨开场："小伙子，我这脚确实是刚才下车那一下崴的，你看。这周围就你在我旁边，你看怎么处理？"
- 道德施压："我也没说一定是你故意的，就事论事。但我这脚肿了是事实吧？你总不能看都不看就走了吧？"
- 威胁报警："你要这么推卸，我现在就报警，到时候警察调监控，是谁的责任谁担。"
**分支走向**：
- 你说"不是我撞的" → 他："我也没说一定是你，但我受伤了啊。"
- 你同意报警 → 他有点慌（因为监控会显示他站错位）。
- 你想私了给钱 → 他开始加码要更多。
**应对方向**：接住"他受伤"但不认领责任。"您脚受伤我看到了，我理解。但车门处是双向人流，责任不是单方面的。咱们报警调监控，该我担的我不推，不该我担的我不白担。"——坚持用监控/流程判定，不私下给钱。

## 模块 C：被拍视频 / 被剪辑 / 被挂网（高毒性）

### C1 对方剪片段拍你发网上
**场景**：小区/餐厅一个小摩擦，对方掏出手机拍你，只拍你表情激动的部分，剪掉他自己先挑事的部分，准备发网上引导网暴你。

#### 无依据版（直接撒泼拍摄）
**人物画像**：觉得拍视频就是正义，你激动他就拍到了"证据"。
**套路菜单**：
- 挑衅式拍："我就拍你怎么了？我还要发网上让大家评评理！"
- 激你："你急了！你看你这表情，我都拍下来了！"
- 拉围观："大家快来看，这人欺负人！"
**应对**：立刻冷静——你现在任何激动都可能被剪成素材。压低声音，明确"你拍可以，但只拍片段是断章取义，我全程也会拍，有事调完整监控"，然后保持冷静。

#### 有依据版（包装型）——训练重点
**人物画像**：聪明、有策略、用"拍证据"包装偷拍，用"发网上"威胁你道歉。
**套路菜单**：
- 平静录像："我拍个视频留个证据哈，刚才你确实态度不好，我发个群里让大家看看。"
- 激你："怎么，你怕被拍？你有理你怕什么？做都做了还不让人说？"
- 勒索："我也不是要怎样，我就想让你当着镜头道个歉，这事就算了。"
- 威胁："不然这视频一发，你工作单位都能被人扒出来。到时候网暴你可别怪我。"
**分支走向**：
- 你激动了 → 他拍到好素材，更得意。
- 你冷静录像反拍 → 他开始慌。
- 你道歉了 → 他拍到了"证据"，但可能继续发。
- 你说"发吧，咱们派出所见" → 他犹豫，因为他知道断章取义发网是违法的。
**应对方向**：不接"你怕什么"的钩，明确划界："你拍你的，但断章取义发网上、威胁公开我个人信息，是违法的。完整监控物业有，我现在就去调。你现在发，咱们派出所见。"——把录像从他的武器变成他的法律风险。**全程保持冷静，不给镜头素材。**

## 模块 D：职场抢功甩锅（扩展）

### D1 抢功型
**场景**：你熬几个月做的项目方案，落地成功后，同事在领导汇报里全程说"我主导的"，把你做的核心工作一笔带过。

#### 无依据版（硬抢型）
**人物画像**：明目张胆抢功，觉得"领导听谁的就是谁的"。
**套路菜单**：
- 当众抢："这个整体框架是我搭的，小X就是打打下手。"
- 被质疑后压人："年轻人多学点，功劳是谁的不重要。"
**应对**：会后找领导同步贡献分工（邮件留痕），不当场情绪化。

#### 有依据版（包装型）——训练重点
**人物画像**：聪明，他确实做了部分工作（对接客户、拍板），于是用这点真实把你做的核心工作稀释成"执行"。
**套路菜单**：
- 模糊功劳："这个项目，我主要负责统筹和最终决策，小X执行了一些具体模块。"
- 你找他后："话也不能这么说——最后定稿确实是我拍板的，客户那边也是我对接的。你做的部分，我在汇报里不是提了'团队协作'嘛。"
- 道德压人："咱们是一个团队，说谁的功劳有意思吗？你这不是让领导难做嘛。"
- 威胁："你要是这么计较，以后这项目你别做了，我自己来。"
**分支走向**：
- 你说"核心方案是我做的" → 他："可最终拍板是我，客户是我对接的啊。"
- 你拿文档/记录出来 → 他有点慌，但嘴上说"我又没说你没做"。
- 你被"计较"绑架、算了 → 他下次继续抢。
- 你找领导 → 他在领导面前装委屈："我就是觉得团队和谐最重要。"
**应对方向**：不否认他做了部分工作（"客户对接确实是你出的面"），但把事实摊开："核心方案是我做的，这部分应该在汇报里写清楚，不是抢谁功劳，是让领导看到真实分工。"——用客观分工/文档记录说话。

### D2 甩锅型
**场景**：上线出了故障，其实是他拍板拍错了一个关键参数，开会时他把锅甩给你。

#### 无依据版（硬甩型）
"这参数当时是你定的吧？出问题怪谁？"
**应对**：翻出当时聊天记录/会议纪要，投屏实锤。

#### 有依据版（包装型）——训练重点
**人物画像**：他"提过顾虑"可能是真的（模糊记忆），于是用这点真实包装成"我提醒过、是你拍板"。
**套路菜单**：
- 半真甩锅："这个参数，我当时是建议再缓缓的，是小X说没问题、坚持要上的。"
- 加码："我确实提过顾虑，但他那边拍了板，我就尊重执行了。"
- 反咬："嗨，我那是综合大家意见，最终还是你这边说可以。你现在这么说，不就是怕担责任吗？"
**分支走向**：
- 你硬否认"他提过" → 他："我明明在群里说过！你翻记录！"（万一真说过，你就翻车）
- 你说"最终拍板是你签的" → 他："我那是综合大家意见啊。"
- 你提议看记录 → 他嘴上说"看就看"，但心里慌。
- 你被"怕担责"激怒 → 他："你看你急了，说你两句还不乐意了。"
**应对方向**：不硬否认"他提过"（万一真提过就翻车），而是拆开："你提没提过顾虑，会议记录里有。但最终上线的决定是谁签批的、谁在群里说'就按这个发'，记录里也写得清楚。我们一起看记录。"——把"谁提醒过"和"谁最终拍板"拆开。

## 模块 E：熟人/亲戚道德绑架（扩展）

### E1 借钱/不还（有依据包装型）
**场景**：亲戚找你借了钱，你催还，他反过来道德绑架。

**人物画像**：确实手头紧（这是真的），于是用"我困难"包装成"你逼我、你不近人情"。

**套路菜单**：
- 卖真惨："我最近确实困难，这个你是知道的。"
- 道德施压："正因为我困难，你现在催我，不是逼我吗？你这么有钱，差这点？"
- 关系绑架："都是亲戚，你要是现在逼我，我在亲戚圈里怎么抬头？你这是让我下不来台。"
- 反咬："我又不是不还，你至于吗？"
**分支走向**：
- 你说"我可以宽限但要定日子" → 他："日子日子，你就这么信不过我？"
- 你被"你有钱"绑架、不好意思催 → 他继续拖。
- 你提借条 → 他脸色变了，开始认真对待。
- 你生气 → 他到处说你"为了点钱六亲不认"。
**应对方向**：承认他困难（"我知道你最近难，不然我也不会拖到现在才提"），但区分：困难≠可以不还。"我可以再宽限两个月，咱定个具体日子写个借条，不是逼你，是把账认清楚。"——不接"你逼我/你小气"，给台阶但守住"要还"的底线。

## 使用说明（AI 对练时）
- 每次从本文件随机抽 1 个模块，默认优先出【有依据版】（训练价值高），无依据版作为对比/调剂。
- **不要念固定台词**——根据用户每句回应即兴演，同一模块每次抽中都要不同。
- 用户答对方向（承认真实+拆穿方式）→ 对方逐步服软；答错（否认/被带跑）→ 对方乘胜追击，评分时判"脱轨回应"。
- 动态分支：用户态度强硬 vs 软弱、是否调用证据（监控/记录/报警）、是否情绪化，都会改变对方的下一步和最终结局——但评分标准始终一致。
